| Fase | Obiettivo / file interessati | Database | Dipendenze | Rischi | Criteri di accettazione | Rollback |

| 0. Baseline | Inventario route, schema distribuito, backup e staging; `docs`, test harness, config deploy. | Dump anonimo e confronto schema, nessuna migrazione produzione. | Accesso autorizzato staging e versione hosting. | Esposizione dati durante dump. | Matrice versioni e schema approvata; backup restore provato. | Nessun cambio applicativo; rimuovere copie temporanee protette. |

Ogni fase deve essere PR piccola, con review e output italiano. Mai eseguire migration su dati reali senza backup verificato, autorizzazione esplicita e piano manutenzione.
