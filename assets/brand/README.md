# Torneo Baone — Brand Kit v1.0

Kit grafico indipendente per il restyling Torneo Baone. La direzione selezionata conserva lo **scudetto**, le **colline**, il **campo** e il **pallone**, con palette navy/oro ispirata al sito storico.

## Cartelle

- `01_loghi/svg/` — loghi vettoriali autonomi e scalabili.
- `01_loghi/png/` — esportazioni raster trasparenti.
- `02_favicon/` — favicon SVG, PNG e ICO.
- `03_pattern/` — sfondi e texture SVG/PNG.
- `04_grafica_social/` — basi grafiche per post, story e banner, senza dati di evento hardcoded.
- `05_ui/` — variabili e stili iniziali, con classi prefissate `tb-`.
- `06_documentazione/` — palette, uso loghi e note tecniche.
- `07_riferimenti/` — tavola visiva generata in chat.

## Avvertenza

I logo SVG sono **ricostruzioni vettoriali originali** coerenti con la tavola creativa approvata, NON tracciati esatti del logo generato nell'immagine. Confrontali visivamente e approva il disegno prima di sostituire il logo sul sito o di mandarli in stampa. Per la stampa professionale verificare anche la resa dei caratteri: il font di fallback nei loghi SVG è DejaVu Sans.

Non sono stati modificati repository, PHP, JavaScript, API o database. Il kit è una base grafica autonoma, non un restyling già integrato.
